## Welcome my saidqb.github.io

Halo! Ini adalah personal site sekaligus tempat aku naruh berbagai tools kecil yang aku bikin buat mempermudah kerjaan sehari-hari sebagai developer. Daripada bolak-balik buka banyak website/tab cuma buat hal-hal simple, saya bikin sendiri versi toolbox-nya di sini.

### 🧰 Toolbox

Kumpulan utility ringan yang bisa langsung dipakai di browser, tanpa install apa-apa:

- **JSON Editor** — Format, minify, dan compare JSON langsung di browser
- **QR Code** — Generate QR code dari teks/URL, atau decode dari gambar/screenshot
- **Base64** — Encode & decode teks ke/dari Base64
- **URL Encoder** — Encode & decode teks/URL (percent-encoding)
- **JWT Decoder** — Lihat isi header & payload token JWT
- **Cron Parser** — Jelaskan cron expression & lihat jadwal berikutnya
- **Markdown Previewer** — Tulis markdown, lihat hasil render-nya langsung
- **Color Picker** — Pilih & convert warna antar format HEX, RGB, HSL
- **Case Converter** — Convert teks ke camelCase, snake_case, kebab-case, dll
- **Text Counter** — Hitung karakter, kata, baris, dan lainnya

Semua tools ini dibuat karena kebutuhan pribadi pas ngoding, jadi kalau ada yang kurang pas atau ada ide fitur baru, feel free buat kasih masukan.
